# Sabores de Colombia – Ruta gastronómica (Grupo 14)

## Cómo abrir y ejecutar
1. Android Studio → File → Open → seleccionar la carpeta `SaboresDeColombia`.
2. Esperar la sincronización de Gradle (Android Studio descarga el wrapper y las dependencias).
3. Crear un emulador de (p. ej. Pixel 9, API 35) y ejecutar la app.
   La pantalla principal está fijada en horizontal para ver los dos fragmentos.

## Pendiente para la Entrega 3
- Reemplazar las imágenes de ejemplo de `res/drawable-nodpi/` (mismo nombre de archivo).
- Cambiar `VIDEO_EJEMPLO` en `datos/DatosRepositorio.java` por el video real de cada plato
  (o poner el .mp4 en `res/raw/` y usar `"android.resource://" + getPackageName() + "/" + R.raw.nombre`).
- Tomar los pantallazos y pegarlos en los recuadros "INSERTAR PANTALLAZO" del documento.
